# 💼 Portfólio Angular

Este projeto é um portfólio desenvolvido com Angular, criado para apresentar minhas habilidades, experiências, projetos e informações de contato de forma moderna, responsiva e interativa.

## 🚀 Visualização Online

Acesse o projeto através do link:

🔗 https://eugeniapaim.github.io/CursoAngularPortifolio/

## 📖 Sobre o Projeto

O objetivo deste portfólio é servir como uma vitrine profissional, reunindo informações relevantes sobre minha trajetória, conhecimentos técnicos e projetos desenvolvidos.

O site foi construído com foco em:

- Design moderno e responsivo
- Boa experiência do usuário (UX)
- Navegação intuitiva
- Componentização utilizando Angular
- Organização e escalabilidade do código

## 🛠️ Tecnologias Utilizadas

- Angular 22
- TypeScript
- HTML5
- CSS3
- Angular Material
- RxJS
